# **App Name**: Rohit Jain, MD

## Core Features:

- Hero Section: Professional homepage with hero section featuring Dr. Jain's name, title, and a brief, impactful subheading.
- About Section: An 'About' section introducing Dr. Jain, including his college and current position.
- Case Study: Detailed case study section focusing on a 'Complex Esophageal Surgery', outlining the surgical procedure and success. Diagrams not included in MVP.
- Academic Profile: Overview of Dr. Jain's academic and clinical profile, teaching experience, and contributions.
- Contact Form: Contact form allowing patients to schedule a consultation. Google Maps integration not included in MVP.
- SEO Optimization: SEO optimization feature ensuring fast loading times, mobile responsiveness, semantic HTML, schema markup, alt tags, meaningful meta tags, and OG tags.

## Style Guidelines:

- Background color: Clean white (#F9FAFB) for a pristine look.
- Primary color: Trustworthy sky blue (#38BDF8) to inspire confidence.
- Accent color: Mint green (#22C55E) for success and vitality.
- Text color: Deep navy (#1E293B) for main text, and medium gray (#64748B) for secondary text, ensuring readability and a professional feel.
- Body and headline font: 'Inter' (sans-serif) for a modern, machined, objective, neutral look, ensuring readability and a professional feel.
- Modern and clean interface, soft shadows, elegant spacing.
- Subtle fade/slide-in animations for a smooth user experience.
